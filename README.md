# AI协同工作台

> **AI提案，人类裁决** —— 一套人机协同流水线底盘，**12个行业场景**。
> 基于开源 [opencode](https://opencode.ai) 作为 Agent 运行时 + Vue3 前端 + MySQL。

## 场景（按行业分组）

### 通用
| 场景 | 流程 | 人工裁决点 |
|---|---|---|
| **智能问数** | 业务问题 → opencode agent 查指标口径 → 生成SQL → 审批卡（SQL+人话解释）→ 执行 → 图表 → 问答沉淀示例库（飞轮） | SQL执行前 |
| **简历初筛** | 批量解析 → 按JD逐份打分 → 候选人卡片（匹配点/风险点/原文引用）→ 盲筛脱敏 | 每张卡片；低分险批量通过 |
| **合同审查** | 合同文本 → AI提取关键条款对照标准模板 → 偏差/缺失/高危分级 | 审查报告复核 |
| **信贷初审** | 借款人档案 → AI自算DTI/月供比+疑点清单 → 授信建议（足额/降额/拒绝） | 授信建议裁决 |

### 互联网
| 场景 | 流程 | 人工裁决点 |
|---|---|---|
| **内容审核** | 30条UGC → AI预审分级（通过/可疑/高危）→ 低危批量放行、高危逐条处置 | 转人工队列 |
| **A/B实验结论** | 实验数据 → AI查核心指标与护栏指标 → 全量/观察/迭代/停止建议 | 全量决策 |

### 制造业
| 场景 | 流程 | 人工裁决点 |
|---|---|---|
| **三单匹配** | 规则引擎比对PO/收货/发票 → 一致自动过 → 差异AI归因处置 | 差异处置 |
| **交期应答CTP** | 销售交期问题 → AI核算产能×物料×在制 → 能/不能/条件方案（分批/紧急/加急料） | 交期承诺确认 |
| **设备维护** | 传感器+停机史+维修记录 → 健康度+故障风险 → 维护建议（窗口/备件/优先级） | 维护工单裁决 |

### 政务
| 场景 | 流程 | 人工裁决点 |
|---|---|---|
| **政务预审** | 材料齐套性/形式合规/信息一致性核对 → 补正告知书草案（一次性告知） | 预审报告复核 |
| **政策匹配** | 企业画像 × 政策条款逐条核对（"政策找企"）→ 推送建议+材料预检 | 推送确认 |
| **12345分派** | 工单文本 → 分类+定责部门+紧急度+相似案例 → 转办备注（会办部门） | 批量确认/改派 |

全部提案与裁决落 `approval_log`（审计日志页可回溯）。


## 快速开始

```bash
# 0) 环境要求：Node 20+
npm install
cp .env.example .env            # 填入你自己的数据库与 LLM 密钥
cp opencode.example.json opencode.json  # 填入 LLM apiKey（问数/政务预审 agent 需要）
cp content/profile.example.md content/profile.md  # 可选：首页个人简历

# 1) 初始化数据库（建表 + 电商演示数据约4万行）
npm run db:reset

# 2) 一键启动（opencode:4096 + 网关:8787 + 前端:5180）
node scripts/start-all.mjs

# 3) 打开 http://localhost:5180
```

> 说明：`.env` / `opencode.json` / `content/profile.md` 均已被 `.gitignore` 忽略，**不会进入仓库**——它们只含你本地的密钥与个人简历。仓库内提供 `.env.example` / `opencode.example.json` / `content/profile.example.md` 作为模板。

### 演示剧本（约10分钟）

1. **首页**（30秒）：一句话定位——AI提案、人类裁决、全程留痕。
2. **智能问数**（3分钟）：输入"上个月华南区销量Top5的商品"→ 看AI调工具查口径字典 → 审批卡上读"我理解为…"的解释 → **通过** → 图表+结论；再问"近三个月销售额月度趋势"演示趋势图；可演示**驳回**（选"口径理解错误"标签）→ AI自动改写重新提案。
3. **简历初筛**（3分钟）：载入简历库（50份）→ 选JD、开盲筛 → 开始AI初筛 → 看候选人卡片（匹配点/风险点带简历原文引用）→ 演示驳回一张（原因标签）→ 一键通过高分候选 → 导出入围名单CSV。
4. **三单匹配**（2分钟）：导入20组 → 14组自动通过 → 6组差异看AI归因（提前开票→暂挂、税率错→退回换开）→ 裁决。
5. **政务预审**（1.5分钟）：载入3件 → 对"刘建国"件AI预审 → 看**补正告知书草案**（一次性列出全部问题+法条引用）→ 复核通过。
6. **审计日志**（30秒）：全部提案/裁决/驳回原因可回溯。

## 首页

- **实时统计**（真实数据，非静态展示）：
  - **访问人数**：去重访客数（匿名 visitorId 存浏览器 localStorage，同一访客30分钟内去重）
  - **在线人数**：近90秒有心跳（45秒/次）的去重访客
  - **使用功能次数**：AI功能实际运行次数（网关级埋点：提问/初筛/差异归因/预审/各场景分析/交期问答），无法前端伪造
  - 更新方式：SSE 事件推送 + 5秒轮询兜底
- **个人简历**：渲染 `content/profile.md`（Markdown），**保存文件即生效**，无需重启。上线后可将该接口替换为后台编辑器。

## 架构

```
Vue3前端(5180, Claude风格, 按行业分组导航)
    │ REST + SSE（/api 代理）
Node网关(8787, Express) ──────────────┐
    │ opencode HTTP API                │ mysql2
opencode serve(4096, 版本锁定)          ▼
    │ 自定义业务工具(stdio MCP)      公网MySQL（电商演示库+应用表+通用biz_case表）
SenseNova LLM
```

- **双轨驱动**：交互式场景走 opencode agent（问数/政务预审）；批量流水线走网关直连LLM（简历/合同/信贷/内容/实验/设备/政策/工单），全部经 `submit_proposal` 式审批。
- **通用业务引擎**（`apps/gateway/biz.mjs` + `packages/shared/scenarios.mjs`）：新场景 = 一段prompt配置 + 一份fixture + 一个Vue视图，统一落 `biz_case` 表与审批流。
- **审批机制**：agent 执行不可逆动作前必须等人工裁决；`run_sql` 校验SQL与审批卡逐字一致；确认过的问答自动沉淀为 few-shot 示例（飞轮）。
- **信任分级**：低风险批量确认（内容审核放行级/工单普通件/简历高分候选），高风险逐条强制细读；驳回必带细粒度原因标签。
- **扩展新场景**：见 `packages/shared/scenarios.mjs`——加一段配置即可接入全部底盘能力（审批卡/审计/SSE/统计/批量）。

## 注意

- LLM价格与模型名变动频繁，`opencode.json` 与 `.env` 中可切换模型（同一key含 deepseek-v4-flash / glm-5.2 等备选）。
- 免费MySQL有连接数限制，连接池已设 max=5。
- 密钥在 `.env`（已 gitignore）；opencode 仅绑定 127.0.0.1。
